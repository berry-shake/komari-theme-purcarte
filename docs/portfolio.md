# 点亮全球与剩余价值

两个功能均由主题实现，不需要服务端或 Agent 新接口。在主题设置的“地图与剩余价值”中分别开关，默认启用，地图默认折叠。

## 展示与筛选

- 点击状态栏“点亮地区”可展开、收起地图，地图标题栏也提供收起按钮，展开和收起不主动改变当前垂直滚动位置。入口跟随“统计栏”和“点亮地区”状态项的显示设置。
- 地图范围跟随分组和名称搜索。点击地图上已点亮地区筛选下方节点，再次点击取消；切换分组或搜索时清除地区筛选。
- 旗帜 emoji 与大小写 ISO 二位代码合并计数。未知地区不点亮、不计数，但显示未识别节点数。离线节点保留点亮，小地区补充圆点。
- 状态栏最后显示“剩余价值”，跟随分组、搜索和地区筛选，在“状态显示设置”中独立开关并保存本机偏好。
- 网格、紧凑和表格视图在账单标签同一行的右侧显示每台服务器的人民币剩余价值，点击金额可查看估算说明和汇率日期；零金额与无法估算的节点不显示金额。
- 只处理当前节点接口返回的可见节点，不请求额外管理数据。

## 独立计算器

顶部搜索按钮左侧提供“剩余价值计算器”，在桌面和手机上均可打开。手工填写周期价格、币种、计费周期（支持自定义天数）、计算时间和到期时间，立即显示原币剩余价值；外币复用浏览器汇率缓存换算人民币，获取汇率失败时保留原币结果。时间按浏览器时区解释，月/年快捷周期明确使用 30/365 天，可用自定义天数调整。

计算器不读取服务器列表、账单或在线状态，不写入服务端，也不受服务器剩余价值开关影响。输入仅用于当前弹窗，关闭后重置；允许零价格，到期价值为零，多周期预付不截断。

## 估值口径

`周期价格 × max(到期时间 - 当前时间, 0) ÷ (周期天数 × 86400000) × 人民币汇率`

按实际剩余毫秒计算，每分钟及返回页面时更新，展示金额保留两位小数。付款周期以后台配置的天数为准，不使用节点创建时间推算账单开始时间；多周期预付不截断为一个周期。

- `price = -1`：免费，计入 0 元；`price = 0`：未填写价格，排除。
- 有效周期账单已到期：计入 0 元。离线不影响剩余价值。
- 一次性/无周期、无有效到期时间、长期（剩余 >= 36500 天）、未知币种/缺失汇率、无效金额：排除。
- 总额仅累加可估算节点，悬停提示中保留已计入与未计入数量，总额为零或全部无法估算时隐藏总额项。
- 后台自动续期只是到期时间配置，不证明实际付款。本功能为余额估算，不代表可退款金额。

兼容后台原有符号：`¥/￥=CNY`、`$=USD`、`€=EUR`、`£=GBP`、`₽=RUB`、`₣=CHF`（瑞士法郎）、`₹=INR`、`₫=VND`、`฿=THB`。还接受大小写标准代码，以及 `HK$`、`S$`、`NT$`、`JP¥`、`A$`、`C$`、`₩` 等别名。其他含义有歧义的自由文本不会猜测换算。

## 浏览器汇率缓存

- 固定请求 `https://api.frankfurter.dev/v2/rates?base=CNY`，免费、无需 Key。一次获取一批币种；报价取倒数转换为“每单位外币等于多少 CNY”。仅外币待估值节点需要发起请求。
- 不发送节点名称、IP、价格、本站 Cookie 或 Referrer；不增加服务端接口。
- `localStorage` key：`purcarte:exchange-rates:v1`。保存版本、来源、获取时间、每个币种的汇率与日期。人民币固定为 1，不依赖接口。
- 成功缓存 24 小时；首次没有缓存时请求。过期先使用旧值，后台刷新，失败继续保留最近有效缓存，显示原始汇率日期及旧缓存提示，15 分钟后允许重试。
- 同一页面的并发消费者共用请求。定时检查、网络恢复及页面重新可见时检查有效期；其他标签页成功写入会通知当前页。缓存不是后台定时任务，浏览器关闭时不会刷新。
- 请求超时 10 秒。验证缓存和接口响应的结构、日期、币种与有限正汇率，核心币种缺失或损坏的响应不覆盖有效缓存。
- localStorage 不可用时降级内存；主题既有“启用本地存储”关闭时也只使用内存。设备/浏览器之间不共享缓存。
- 日汇率可能因周末、节假日或来源而不是当天日期；显示接口实际日期，不把获取时间当作汇率日期。

## 本地地图

地图交互方案参考 [Nezha Dash](https://github.com/hamster1963/nezha-dash/blob/606b123c813bdaf887f3fc1ba987311dc654c96d/app/%28main%29/ClientComponents/main/InteractiveMap.tsx)：d3-geo 等距圆柱投影、SVG 地区高亮、小地区圆点及服务器浮层。使用 Komari 的 `region`、`uuid`、`name` 和实时在线状态；投影路径预先生成，浏览器只渲染 SVG。

地图采用 Natural Earth 1:50m 数据，离线预投影为 SVG 路径，随主题打包。地图按原比例居中显示，高度不超过 440px 或视口高度的 50%。地图采用弱化底色与主题强调色，悬停可查看该地区服务器与在线状态；移动端点击后在地图下方展示。地图组件只在首次展开时加载，没有地图 Key、瓦片请求、IP 定位调用或运行时地图依赖。

- 源数据：<https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_50m_admin_0_countries.geojson>
- 许可：Natural Earth 数据为 public domain，<https://www.naturalearthdata.com/about/terms-of-use/>。
- 生成：`scripts/generate-world-map.mjs`，使用 `d3-geo@3.1.1` 的 等距圆柱投影和路径生成器（生成工具依赖，未引入主题依赖）。输出 `src/assets/world-map.json` 和 `world-regions.json`。

重建资源示例（把 d3-geo 安装到临时目录）：

```sh
npm install --prefix /tmp/purcarte-map-tools d3-geo@3.1.1
curl -fL 'https://raw.githubusercontent.com/nvkelso/natural-earth-vector/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_50m_admin_0_countries.geojson' -o /tmp/purcarte-countries.geojson
node scripts/generate-world-map.mjs /tmp/purcarte-countries.geojson /tmp/purcarte-map-tools/node_modules/d3-geo/src/index.js
```

```sh
yarn install --frozen-lockfile
yarn test
yarn lint
yarn build
```
